# Weave: Editorial Fashion Showcase

Build a frontend-only responsive clothing e-commerce website called “Weave” from the provided specification. Use static product data and no backend. Bright warm editorial fashion visual style: cream/off-white, consistent terracotta accent, charcoal text, no dark mode or black backgrounds. Include Home with Men/Women tabs and 6-8 products each, product details, cart with working local state and premium Sentinel Protection UI toggle, 3-step checkout, processing state, and toggleable Success/Payment Paused alert outcomes. Keep clean modular components, responsive mobile-first layout, thoughtful hover and subtle animation.
